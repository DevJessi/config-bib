# ADR-008: Multa por atraso
- **Status**: Em análise  
- **Data**: 2026-09-15  
- **Contexto**  
<a href="../docs-US/US-06 — Calcular multa por atraso.md">US-06</a> prevê cálculo automático de multa, mas não há RN específica.  
- **Decisão**  
Criar RN para **cálculo automático de multa por atraso** com base em dias excedidos.  
- **Alternativas consideradas**  
  - Multa fixa independente do atraso.  
  - Multa manual pelo bibliotecário.  
- **Consequências**  
  - Automatiza cobrança.  
  - Evita arbitrariedade.  
- **Referências**  
<a href="../docs-US/US-06 — Calcular multa por atraso.md">US-06</a>,
