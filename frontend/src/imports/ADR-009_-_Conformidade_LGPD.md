# ADR-009: Conformidade LGPD
- **Status**: Em análise 
- **Data**: 2026-09-15  
- **Contexto**  
<a href="../docs-RNF/RNF-05 — Conformidade com a LGPD.md">RNF-05</a> exige conformidade com LGPD.  
- **Decisão**  
Implementar **exclusão de dados em até 48h** após solicitação.  
- **Alternativas consideradas**  
  - Exclusão imediata sem prazo.  
  - Exclusão manual por administrador.  
- **Consequências**  
  - Cumpre legislação.  
  - Exige processos automatizados de exclusão.  
- **Referências**  
<a href="../docs-RNF/RNF-05 — Conformidade com a LGPD.md">RNF-05</a>.
