# ADR-003: Notificação de vencimento
- **Status**: Concluído  
- **Data**: 2026-09-15  
- **Contexto**  
<a href="../docs-US/US-03 — Receber lembrete de vencimento.md">US-03</a> prevê lembrete de devolução, mas não há RF correspondente.  
- **Decisão**  
Criar RF específico para **notificação automática de vencimento** via e-mail.  
- **Alternativas consideradas**  
  - Não implementar notificações.  
  - Notificações manuais pelo bibliotecário.  
- **Consequências**  
  - Reduz multas por esquecimento.  
  - Exige integração com serviço de e-mail.  
- **Referências**  
<a href="../docs-US/US-03 — Receber lembrete de vencimento.md">US-03</a>, 
<a href="../docs-RN/RN-03 — Pendência financeira acima de R$20,00 bloqueia empréstimo.md">RN-03</a>.
