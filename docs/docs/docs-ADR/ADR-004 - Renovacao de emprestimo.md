# ADR-004: Renovação de empréstimo
- **Status**: Concluído  
- **Data**: 2026-09-15  
- **Contexto**  
<a href="../docs-RN/RN-02 — Reserva impede renovação.md">RN-02</a> define que reserva impede renovação, mas não há RF correspondente.  
- **Decisão**  
Criar RF para **renovação de empréstimos**, respeitando reservas ativas.  
- **Alternativas consideradas**  
  - Não permitir renovação.  
  - Renovação sem considerar reservas.  
- **Consequências**  
  - Garante justiça entre leitores.  
  - Exige verificação de reservas antes da renovação.  
- **Referências**
