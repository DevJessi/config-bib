# ADR-010: Acessibilidade
- **Status**: Concluído   
- **Data**: 2026-09-15  
- **Contexto**  
<a href="../docs-RNF/RNF-06 — Acessibilidade.md">RNF-06</a> exige conformidade WCAG 2.1 nível AA.  
- **Decisão**  
Adotar **design inclusivo** seguindo WCAG 2.1 AA.  
- **Alternativas consideradas**  
  - Nível A apenas.  
  - Não seguir diretrizes.  
- **Consequências**  
  - Garantia de acessibilidade.  
  - Aumenta esforço de design e testes.
