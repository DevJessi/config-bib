# ADR-006: Bloqueio por multa
- **Status**: Concluído   
- **Data**: 2026-09-15  
- **Contexto**  
<a href="../docs-RN/RN-03 — Pendência financeira acima de R$20,00 bloqueia empréstimo.md">RN-03</a> prevê bloqueio por multa acima de R$ 20, mas não detalha desbloqueio.  
- **Decisão**  
Definir que **bloqueio só é retirado após quitação total da pendência**.  
- **Alternativas consideradas**  
  - Permitir desbloqueio parcial.  
  - Bloqueio permanente até intervenção manual.  
- **Consequências**  
  - Garante regularização financeira.  
  - Pode gerar insatisfação em leitores inadimplentes.
