# RF-002 — Cadastro de livros e exemplares

## Identificação

* **Código:** RF-002
* **Nome:** Cadastro de livros e exemplares
* **Tipo:** Requisito Funcional
* **Ator relacionado:** Bibliotecário

## Descrição

O sistema deve permitir o cadastro das informações bibliográficas dos livros e de seus respectivos exemplares, possibilitando o controle individual de cada exemplar disponível no acervo.

## User Story relacionada

**Como** bibliotecário, **eu quero** cadastrar livros e seus exemplares **para que** o acervo possa ser organizado e os exemplares possam ser controlados durante os empréstimos.

## Critérios de aceitação

* O sistema deve permitir cadastrar:

  * título;
  * autor;
  * ISBN;
  * ano de publicação;
  * editora;
  * edição;
  * gênero;
  * categoria.
* O sistema deve permitir cadastrar um ou mais exemplares para cada livro.
* Cada exemplar deve possuir uma identificação própria.
* O sistema deve permitir controlar o status de cada exemplar.
* O cadastro deve ser armazenado no banco de dados.
