
# RF-011 — Consultar histórico de empréstimos

## Identificação

* **Código:** RF-011
* **Nome:** Consultar histórico de empréstimos
* **Tipo:** Requisito Funcional
* **Ator relacionado:** Leitor / Bibliotecário

## Descrição

O sistema deve permitir a consulta do histórico de empréstimos realizados, incluindo informações sobre retirada, devolução e situação dos empréstimos.

## User Story relacionada

**Como** usuário, **eu quero** consultar o histórico de empréstimos **para que** eu possa acompanhar os livros que já foram emprestados e devolvidos.

## Critérios de aceitação

* O sistema deve registrar os empréstimos realizados.
* O sistema deve registrar as devoluções realizadas.
* O leitor deve conseguir consultar seu próprio histórico.
* O bibliotecário deve conseguir consultar o histórico relacionado aos leitores e exemplares.
* O histórico deve apresentar informações suficientes para identificar o empréstimo.
