# RF-001 — Cadastro de usuário

## Identificação

* **Código:** RF-001
* **Nome:** Cadastro de usuário
* **Tipo:** Requisito Funcional
* **Ator relacionado:** Leitor

## Descrição

O sistema deve permitir que novos usuários realizem seu cadastro para acessar a plataforma e utilizar as funcionalidades destinadas aos leitores.

## User Story relacionada

**Como** leitor, **eu quero** realizar meu cadastro **para que** eu possa acessar o sistema e utilizar os serviços da biblioteca.

## Critérios de aceitação

* O sistema deve permitir o preenchimento de nome, CPF, e-mail e senha.
* O sistema deve validar os dados informados.
* Ao confirmar um cadastro válido, o sistema deve criar o perfil do leitor.
* A senha não deve ser exibida ou armazenada de forma insegura.
* O usuário deve conseguir acessar o sistema após o cadastro.
