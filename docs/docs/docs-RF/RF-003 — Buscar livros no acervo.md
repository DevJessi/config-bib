# RF-003 — Buscar livros no acervo

## Identificação

* **Código:** RF-003
* **Nome:** Buscar livros no acervo
* **Tipo:** Requisito Funcional
* **Ator relacionado:** Leitor

## Descrição

O sistema deve permitir que o leitor pesquise livros no acervo utilizando informações como título, autor ou edição e visualize os resultados encontrados e a situação dos respectivos exemplares.

## User Story relacionada

**Como** leitor, **eu quero** buscar livros por título, autor ou edição **para que** eu possa encontrar rapidamente o livro que desejo.

## Critérios de aceitação

* O usuário deve conseguir informar um termo de pesquisa.
* O sistema deve permitir pesquisa por título, autor ou edição.
* O sistema deve apresentar os livros correspondentes à pesquisa.
* O sistema deve apresentar a situação dos exemplares encontrados.
* O resultado deve permitir identificar se o exemplar está disponível, emprestado ou reservado.
