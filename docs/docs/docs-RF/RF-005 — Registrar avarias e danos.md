# RF-005 — Registrar avarias e danos

## Identificação

* **Código:** RF-005
* **Nome:** Registrar avarias e danos
* **Tipo:** Requisito Funcional
* **Ator relacionado:** Bibliotecário

## Descrição

O sistema deve permitir que o bibliotecário registre avarias identificadas em exemplares devolvidos, gerando uma cobrança de R$15,00 e mantendo o registro da ocorrência.

## User Story relacionada

**Como** bibliotecário, **eu quero** registrar danos encontrados nos exemplares devolvidos **para que** a biblioteca mantenha o controle das avarias e dos valores devidos pelo leitor.

## Critérios de aceitação

* O bibliotecário deve conseguir registrar uma avaria em um exemplar.
* O sistema deve registrar a ocorrência vinculada ao leitor e ao exemplar.
* O sistema deve gerar uma cobrança de **R$15,00** referente à avaria.
* A cobrança deve ser registrada como pendência financeira.
* A pendência causada pela avaria deve impedir novos empréstimos enquanto não for quitada.
* Após o pagamento da pendência, o bloqueio causado pela avaria deve ser removido.
