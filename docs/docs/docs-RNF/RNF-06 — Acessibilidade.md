
# RNF-06 — Acessibilidade

## Identificação

* **Código:** RNF-06
* **Nome:** Acessibilidade
* **Tipo:** Requisito Não Funcional
* **Ator relacionado:** Sistema / Usuário

## Descrição

A interface do sistema deve seguir as recomendações de acessibilidade da **WCAG 2.1 nível AA**.

## Critérios de aceitação

* Os elementos da interface devem possuir estrutura acessível.
* O sistema deve permitir navegação adequada por teclado.
* Os conteúdos devem possuir contraste e identificação adequados.
* Os componentes devem seguir as recomendações aplicáveis da WCAG 2.1 AA.
