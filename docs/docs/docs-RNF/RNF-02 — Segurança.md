
# RNF-02 — Segurança

## Identificação

* **Código:** RNF-02
* **Nome:** Segurança
* **Tipo:** Requisito Não Funcional
* **Ator relacionado:** Sistema

## Descrição

O sistema deve proteger os dados dos usuários e utilizar mecanismos adequados de segurança para autenticação e comunicação.

## Critérios de aceitação

* As senhas devem ser armazenadas utilizando **bcrypt**.
* Os dados armazenados devem possuir proteção adequada.
* A comunicação da aplicação deve utilizar **HTTPS**.
