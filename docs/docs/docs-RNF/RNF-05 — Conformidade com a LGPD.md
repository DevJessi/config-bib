
# RNF-05 — Conformidade com a LGPD

## Identificação

* **Código:** RNF-05
* **Nome:** Conformidade com a LGPD
* **Tipo:** Requisito Não Funcional
* **Ator relacionado:** Sistema / Leitor

## Descrição

O sistema deve atender aos requisitos aplicáveis da Lei Geral de Proteção de Dados (LGPD).

## Critérios de aceitação

* Os dados pessoais devem ser tratados de forma adequada.
* O sistema deve permitir a solicitação de exclusão dos dados pessoais pelo leitor, quando aplicável.
* As solicitações de exclusão devem ser atendidas em até **48 horas**, conforme definido pelo projeto.
