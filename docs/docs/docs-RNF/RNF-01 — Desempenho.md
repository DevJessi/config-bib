
# RNF-01 — Desempenho

## Identificação

* **Código:** RNF-01
* **Nome:** Desempenho
* **Tipo:** Requisito Não Funcional
* **Ator relacionado:** Sistema

## Descrição

A API deve apresentar tempo de resposta inferior a **200 ms** sob uma carga de até **500 requisições por segundo**.

## Critérios de aceitação

* As requisições devem ser processadas em menos de 200 ms no cenário definido.
* O sistema deve ser testado considerando até 500 requisições por segundo.
