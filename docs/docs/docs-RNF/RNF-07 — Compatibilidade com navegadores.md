
# RNF-07 — Compatibilidade com navegadores

## Identificação

* **Código:** RNF-07
* **Nome:** Compatibilidade com navegadores
* **Tipo:** Requisito Não Funcional
* **Ator relacionado:** Sistema / Usuário

## Descrição

O sistema deve funcionar nos principais navegadores utilizados pelos usuários.

## Critérios de aceitação

O sistema deve ser compatível com as **duas versões mais recentes** dos seguintes navegadores:

* Google Chrome;
* Mozilla Firefox;
* Microsoft Edge;
* Safari.
