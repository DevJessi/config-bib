
# RNF-04 — Usabilidade

## Identificação

* **Código:** RNF-04
* **Nome:** Usabilidade
* **Tipo:** Requisito Não Funcional
* **Ator relacionado:** Leitor

## Descrição

O sistema deve permitir que um novo leitor consiga realizar seu primeiro empréstimo em menos de **3 minutos**, considerando que o livro esteja disponível e não existam impedimentos.

## Critérios de aceitação

* O fluxo deve ser simples e compreensível.
* Um novo leitor deve conseguir concluir seu primeiro empréstimo em menos de 3 minutos no cenário definido.
