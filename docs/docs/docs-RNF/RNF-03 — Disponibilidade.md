
# RNF-03 — Disponibilidade

## Identificação

* **Código:** RNF-03
* **Nome:** Disponibilidade
* **Tipo:** Requisito Não Funcional
* **Ator relacionado:** Sistema

## Descrição

O sistema deve possuir disponibilidade mínima de **99,5%**.

## Critérios de aceitação

* A indisponibilidade mensal não deve ultrapassar aproximadamente 3,6 horas.
* O sistema deve permanecer acessível durante a maior parte do período de operação.
